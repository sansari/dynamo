# Changelog

## 2026-10-13


### Added

- - Added the `dynamo` CLI with a local React first-run wizard that discovers the current repository, narrows a product concern, persists progress, and creates an agent-agnostic requirements handoff.
  - Added `dynamo dash` for opening a read-only repository specifications dashboard directly, including requirement text, source paths, format issues, and manual refresh.
  - Added a generated promotion-shop example repository for repeatable first-run demonstrations.

### Changed

- Refined the repository dashboard with a light theme, selectable specification navigation, compact repository context in the header, and requirement hover/focus popovers showing covering tests and quality-review status.
